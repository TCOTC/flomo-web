# flomo 停靠栏

在思源停靠栏中打开 [flomo](https://flomoapp.com/) 网页。把卡片拖进编辑器即可插入块；换行会拆成独立段落。

主要用于把 flomo 里的笔记迁到思源。

## 使用

1. 启用插件后，右侧停靠栏会出现 flomo 图标
2. 在停靠栏中登录 flomo
3. 将卡片拖到思源文档中

仅桌面端（Windows / macOS / Linux）可用。浏览器端和移动端没有 `<webview>`，无法嵌入 flomo 网页。

实现参考了 [Web 工具集成](https://github.com/zuoez02/siyuan-plugin-webview-flomo)。
