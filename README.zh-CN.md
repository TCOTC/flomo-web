# flomo 浮墨笔记网页版

在思源的页签或停靠栏中打开 [flomo](https://flomoapp.com/) 网页。登录态会记住；把卡片拖进编辑器即可插入块，换行会拆成独立段落。图片和录音会在放下后转存为思源资源。

## 使用

1. 启用插件后，点击顶栏左侧的 flomo 图标打开网页页签（每次新开）；右侧停靠栏也可打开，停靠栏始终是首页
2. 在网页中登录 flomo
3. 编辑器里左键点击 flomo 链接会用新页签打开；中键仍走系统浏览器
4. 将卡片拖到思源文档中（网页里复制粘贴不会走这套转换）
5. 正在编辑的卡片不能拖；不要把卡片从一块 flomo 网页拖过另一块 flomo 网页，drop 可能被挡住
6. flomo 域外的链接在系统浏览器打开

仅桌面端（Windows / macOS / Linux）可用。浏览器端和移动端没有 `<webview>`，无法嵌入 flomo 网页。
