# flomo 浮墨笔记网页版

在思源的页签或停靠栏中打开 [flomo](https://flomoapp.com/) 网页。登录态会记住；把卡片拖进编辑器即可插入块，换行会拆成独立段落。

## 使用

1. 启用插件后，点击顶栏左侧的 flomo 图标打开网页页签；右侧停靠栏也可打开
2. 在网页中登录 flomo
3. 编辑器里点击 flomo 链接会用新页签打开
4. 可将卡片拖到思源文档中

仅桌面端（Windows / macOS / Linux）可用。浏览器端和移动端没有 `<webview>`，无法嵌入 flomo 网页。
