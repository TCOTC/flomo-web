# flomo Dock

Show the [flomo](https://flomoapp.com/) web app in a SiYuan dock. Drag a card into the editor to insert it as blocks; line breaks become separate paragraphs.

Intended for migrating notes out of flomo.

## Usage

1. Enable the plugin. A flomo icon appears on the right dock.
2. Sign in to flomo in the dock.
3. Drag a card into a SiYuan document.

Desktop app only (Windows / macOS / Linux). The `<webview>` tag is not available in the browser or on mobile.

Inspired by [siyuan-plugin-webview-flomo](https://github.com/zuoez02/siyuan-plugin-webview-flomo).
