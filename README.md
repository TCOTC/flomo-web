# flomo Web

Open the [flomo](https://flomoapp.com/) web app in a SiYuan tab or dock. Sign-in is remembered. Drag a card into the editor to insert it as blocks; line breaks become separate paragraphs. Images and audio are saved into SiYuan assets after the drop.

## Usage

1. After enabling the plugin, click the flomo icon on the left of the top bar to open a web tab (always a new tab). You can also open it from the right dock, which always shows the home page.
2. Sign in to flomo in the embedded page.
3. Left-clicking a flomo link in the editor opens it in a new tab. Middle-click still uses the system browser.
4. Drag cards into a SiYuan document (copy-paste from the web page does not use this converter).
5. A card being edited cannot be dragged. Do not drag a card across another flomo webview, or the drop may be swallowed.
6. Links outside the flomo domain open in the system browser.

Desktop app only (Windows / macOS / Linux). The `<webview>` tag is not available in the browser or on mobile.
