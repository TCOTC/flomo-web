# flomo Web

Open the [flomo](https://flomoapp.com/) web app in a SiYuan tab or dock. Sign-in is remembered. Drag a card into the editor to insert it as blocks; line breaks become separate paragraphs.

## Usage

1. After enabling the plugin, click the flomo icon on the left of the top bar to open a web tab. You can also open it from the right dock.
2. Sign in to flomo in the embedded page.
3. Clicking a flomo link in the editor opens it in a new tab.
4. Drag cards into a SiYuan document.

Desktop app only (Windows / macOS / Linux). The `<webview>` tag is not available in the browser or on mobile.
